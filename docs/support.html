FAQ

常见问题

如何编译 CliJudge？

推荐 npm install -g clijudge 一键安装（需 Node.js ≥ 14，含双平台预编译二进制）；或在 Releases 下载预编译二进制（clijudge.exe / clijudge-linux.bin）。需要自行编译时，使用 CMake：

mkdir build
cd build
cmake ..
cmake --build .

或使用 g++ 直接编译（Windows）：

g++ -std=c++17 -O2 -Wall -static -I include \
  -o clijudge.exe src/main.cpp \
  -lpsapi -luserenv -lole32 -lwinhttp

Windows Vista 兼容：必须保留 -static，否则会缺少 libgcc_s_seh-1.dll 等运行库；且 Vista 不含 UCRT，需用 MSVCRT 版工具链（winlibs *-msvcrt 或 MSYS2 的 MINGW64），UCRT 版工具链产出的 exe 仅支持 Windows 10+。

Linux 下无平台链接参数：

g++ -std=c++17 -O2 -Wall -I include \
  -o clijudge src/main.cpp

数据存储在哪里？

默认存储在可执行文件同级目录的 data/ 文件夹下。可通过环境变量 CLIJUDGE_DATA_DIR 自定义存储位置。题目、文章、比赛、提交分别位于 data/problems、data/articles、data/contests、data/submissions 子目录，旧版平铺数据会在启动时自动迁移。索引写入采用临时文件 + 原子替换，并发修改由 data/.clijudge.lock 跨进程锁保护（进程崩溃后锁自动释放）。

数据以 JSON 格式存储，方便备份和迁移。

支持哪些编程语言？

  • C / C++ (.c, .cpp, .cc, .cxx)
  • Python 3 (.py)
  • Java (.java)
  • JavaScript (.js)
  • 自定义语言（judge.custom_languages 注册任意扩展名）

按扩展名自动检测语言类型，无需手动指定。

如何导入导出题目？

# 导出题目
clijudge.exe problem export 1 problem_1.json

# 导入题目
clijudge.exe problem import problem_1.json
Troubleshooting

故障排除

编译错误

  1. 找不到 json.hpp 确保 json.hpp 文件在 include/ 目录。
  2. 找不到 Windows API 函数 确保链接了正确的库：-lpsapi -luserenv -lole32 -lwinhttp
  3. C++17 支持错误 确保编译器支持 C++17，使用 -std=c++17 选项。

运行时错误

  1. 无法创建数据目录 检查写入权限，或设置 CLIJUDGE_DATA_DIR 到有权限的目录。
  2. 沙箱执行失败 Windows 下尝试以管理员身份运行，或检查 Windows 安全设置；Linux 下无需 root，评测前会自动做环境能力预检并在加固系统（如 Ubuntu 24.04）降级，若仍失败请到 GitHub Issues 反馈并附系统版本。
  3. 找不到编译器 对于 C/C++ 代码，确保 g++ 在系统 PATH 中。
